## The one skill

`01-build-your-own-crm` sits beside the discovery skills from earlier drops, and goes one step
further. `member-business-interview` writes your business down as files. This one interviews you far
deeper, writes a PRD you approve, forks the open source CRM base and builds your platform on a production
stack: Next.js, Postgres on Supabase, better-auth, Resend, Inngest and Railway.

Run it from a CLI agent:

```
Read build-your-own-crm/SKILL.md and follow it.
```

Nothing is built until you type `APPROVE PRD`. The scope can change at any point, and the PRD changes
first.
