# The reference bank

> **This ships empty on purpose.** The original held one company's own material, which would make
> your output look like theirs. The structure below is the part that transfers. Fill it in once and
> every format in this repo starts reading from it.
>
> Fastest way to fill it: run `funnel-builder` or `member-business-interview` in the same workspace
> first. Their corpus pass produces most of what goes here, in your buyers' own words.

What each file here is for, and the order the format skills read them in.

| File | What belongs in it | Filled by |
|---|---|---|
| `spine.md` | Your canonical examples. A piece that worked, the structure under it, why it worked. | You, after ten real pieces |
| `hooks/HOOKS.md` | Every hook shape you are allowed to use, with an id each. Hooks get filled from here, never free-written. | Scraping your own winners |
| `canon/angles-and-formats.md` | The fixed list of angles and formats. Ideation picks from this list only. | You, once |
| `canon/model-routing.md` | Which generation model owns which shot type, with verified ids and parameters. | You, per tool |
| `canon/objection-bank.md` | Every objection, counted, with the honest answer. | Sales calls |
| `canon/CONCEPT-BANK.md` | Cleared concepts waiting to be produced. | Ongoing |
| `scripts/archetypes.md` | Your buyer archetypes and the language each responds to. | The funnel-builder interview |
| `scripts/core-pain-vsl-scripts.md` | Long-form scripts that have already sold. | You |
| `ai-tells-banlist.md` | Words and constructions that make copy read as machine-written. | Start from the list below |
| `meta-ads-media-buying.md` | How you actually buy, so the copy matches the placement. | Your media buyer |
| `../config/brand-kit.house.md` | Palette, typefaces, aspect specs, visual do and do-not. | You, once |
| `../config/content-strategy.house.md` | The format families and the operating contract. | You, once |

Nothing here is optional if you want output that sounds like you. A format skill with an empty
reference bank produces competent generic work, which is the thing you are trying to avoid.
