# The hook bank

> **This ships empty on purpose.** The original held one company's own material, which would make
> your output look like theirs. The structure below is the part that transfers. Fill it in once and
> every format in this repo starts reading from it.
>
> Fastest way to fill it: run `funnel-builder` or `member-business-interview` in the same workspace
> first. Their corpus pass produces most of what goes here, in your buyers' own words.

Hooks are **filled from this file**, never free-written. Every hook you use cites an id from here.

## How to build it

1. Collect thirty openers that stopped you personally in your own market.
2. For each, strip the specifics and write down the shape that is left.
3. Give it an id (`H-001`), a name, and one line on when it works.
4. Add your own winners as they appear, with the number that proved it.

## Entry template

```
id: H-001
name: <short name for the shape>
shape: <the structure with the specifics removed>
works when: <the condition, in one line>
avoid when: <when this shape reads as a trick>
example: <one of yours, or one you collected, marked which>
proof: <the number, if you have one>
```

## Rules that carry

- One idea per hook. A hook with two ideas is two hooks.
- Name the reader's situation, not your product category.
- If the hook could run for a competitor unchanged, it is not a hook yet.
