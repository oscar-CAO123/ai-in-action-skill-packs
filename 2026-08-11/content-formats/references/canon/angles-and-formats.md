# The angle and format matrix

> **This ships empty on purpose.** The original held one company's own material, which would make
> your output look like theirs. The structure below is the part that transfers. Fill it in once and
> every format in this repo starts reading from it.
>
> Fastest way to fill it: run `funnel-builder` or `member-business-interview` in the same workspace
> first. Their corpus pass produces most of what goes here, in your buyers' own words.

The fixed lists. Ideation picks from these and nothing else, which is what stops an agent inventing
a new format every week.

## Angles

```
id: A1
name: <the angle>
belief it attacks: <what the reader currently thinks>
belief it installs: <what they think afterwards>
proof it needs: <what must be true for this to be honest>
```

Eight to twelve is the right number. Fewer and you repeat, more and nothing gets made twice.

## Formats

```
id: F1
name: <the format>
output: <static, carousel, short video, long video>
when to use: <the job it does>
cost: <rough, per unit>
build path: <which skill in formats/ produces it>
```

Only list formats you have actually shipped once.
