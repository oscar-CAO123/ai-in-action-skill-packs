## What is new in this drop

- **`02-share-your-skills`** is new. It is this repository, reverse engineered: it walks you through
  turning your own skills folder into a GitHub repository that installs as a plugin, checks for
  credentials and client names before anything is public, validates it, and hands your team two
  lines.
- **`06-stop-the-slop`** is new. Two passes that take the signs of AI writing out of anything going
  in front of customers, grounded in the StoryScope study. The full implementation it links to is
  `github.com/NulightJens/humanizer-stack`.
- **`03-computer-use`** is new as a grouping. One router over four skills in the order to try them
  in, and it now includes `build-headless-cli`, which earlier drops did not have.
