# Automation routing

Source: https://www.youtube.com/watch?v=CB5bG4mvnS0

Use an API when available because it is usually fastest, cheapest, and most consistent. Use a deterministic macro when the same fixed actions always work and no reasoning is required. Use browser or computer use when the next action depends on vision, changing state, or judgement. A custom headless CLI belongs between API and macro when stable selectors, endpoints, or local files can expose a reliable command contract.
